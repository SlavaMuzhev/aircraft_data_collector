# Проект Aircraft Data Collector

## Описание:
Приложение для сбора и анализа данных о самолетах, 
находящихся в воздушном пространстве выбранных стран. 
Программа использует API Nominatim для получения координат 
и API OpenSky Network для отслеживания полетов в реальном времени. 
Данные валидируются и сохраняются в JSON-формат для последующего анализа.

### Основные модули 

* Модуль в корне проекта *main.py* предоставляет консольный интерфейс для взаимодействия 
с пользователем: запрос данных по стране, вывод ТОП-N самолетов по высоте и поиск по стране регистрации.

В директории **src** реализована логика приложения согласно принципам SOLID и ООП

* Модуль **api.py** содержит класс APIAdapter, который:

1. Подключается к OpenStreetMap для получения географических границ стран
2. Запрашивает данные о всех активных самолетах в указанных координатах

* Модуль *aeroplane.py* содержит класс Aeroplane:

1. Инкапсулирует данные о самолете (позывной, страна, скорость, высота)
2. Валидирует входящие данные от API.
их в основную функцию
3. Поддерживает магические методы для сравнения самолетов между собой по скорости и высоте.

* Модуль *connect_json.py* реализует класс ConnectJson для работы с хранилищем:

1. Позволяет добавлять, искать и удалять записи в JSON-файле.
2. Автоматически создает структуру папок для хранения данных.

* Модули *base_api_adapter.py* и *base_file_connect.py* содержат абстрактные классы, 
задающие архитектуру для расширения проекта (например, добавление других API или баз данных).

## Установка

1. Клонируйте репозиторий:

`git clone git@github.com:SlavaMuzhev/aircraft_data_collector.git`

2. Перейдите в папку проекта:

`cd C:\Users\........\aircraft_data_collector>`

3. Установка зависимостей:

`pip install -r requirements.txt`

## Зависимости
* Python 3.x
* requests — для работы с внешними API.
* pytest и pytest-cov — для тестирования и анализа покрытия кода.

## Тестирование
Для тестирования используется библиотека **pytest**

Тестами покрываются все функции, находящиеся в модулях из пакета src

Установка pytest:

`poetry add --group dev pytest`

Запуск pytest удобнее всего производить из PyCharm. 
Для этого выполните следующие шаги:
1. Откройте окно Edit Configurations
2. Нажмите на "+" для создания новой конфигурации и выберите pytest
3. Укажите директорию с тестами и директорию проекта в целом

В pytest для анализа покрытия кода надо поставить библиотеку 
**pytest-cov**

Через poetry с добавлением в отдельную группу:

`poetry add --group dev pytest-cov`

Чтобы запустить тесты с оценкой покрытия, можно воспользоваться следующими командами:

`pytest --cov`  — при активированном виртуальном окружении.
